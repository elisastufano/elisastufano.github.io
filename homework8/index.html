01 / Correlation

Covariance and the correlation coefficient

Covariance measures how two variables move together. Dividing by the standard deviations removes the units and gives a number between −1 and 1.

Definitions

For random variables X, Y with finite variances, μX = E[X], μY = E[Y]:

Cov(X,Y) = E[(X − μX)(Y − μY)] = E[XY] − μXμY
ρ = Corr(X,Y) = Cov(X,Y) / (σX σY)

For a sample (x₁,y₁),…,(xn,yn) with means x̄, ȳ define the sums of squares and products

Sxx = Σ(xᵢ − x̄)² , Syy = Σ(yᵢ − ȳ)² , Sxy = Σ(xᵢ − x̄)(yᵢ − ȳ)
r = Sxy / √(Sxx Syy)

The factors 1/n or 1/(n−1) cancel in r, so r does not depend on which convention is used.

Why |ρ| ≤ 1

Let U = X − μX, V = Y − μY. For every real t,

0 ≤ E[(U − tV)²] = E[U²] − 2t E[UV] + t² E[V²]

A quadratic in t that is never negative has non-positive discriminant:

(E[UV])² ≤ E[U²] E[V²]  ⇒  Cov(X,Y)² ≤ σX² σY²

Equality holds iff U = tV almost surely, i.e. iff Y is an exact linear function of X. So ρ = ±1 exactly in the perfectly linear case (Cauchy–Schwarz inequality).

Properties

Dimensionless. Invariant under positive affine maps (X → aX + c, a > 0) and changes sign under a negative one. Symmetric: Corr(X,Y) = Corr(Y,X).

What it measures

Only linear association. A perfect non-linear relation such as Y = X² can have ρ = 0. It is also sensitive to outliers and says nothing about causation.

Standardized form

With z-scores zx = (x − x̄)/sx, zy = (y − ȳ)/sy, the correlation is the average product of the z-scores: r = (1/n) Σ zₓ·zy (with s computed using divisor n).

02 / Least squares

Solving the regression problem for a and b

We look for the line ŷ = a + b·x that makes the vertical errors as small as possible in the sum-of-squares sense.

The optimization problem

minimize   S(a,b) = Σᵢ (yᵢ − a − b xᵢ)²

1Derivative with respect to a. Setting ∂S/∂a = −2 Σ(yᵢ − a − b xᵢ) = 0 gives

ȳ = a + b x̄  ⇒  a = ȳ − b x̄

The line always passes through the centroid (x̄, ȳ).

2Derivative with respect to b. Setting ∂S/∂b = −2 Σ xᵢ(yᵢ − a − b xᵢ) = 0 and substituting a:

Σ xᵢ(yᵢ − ȳ) = b Σ xᵢ(xᵢ − x̄)

Since Σ x̄(yᵢ − ȳ) = 0 and Σ x̄(xᵢ − x̄) = 0, we may replace xᵢ by (xᵢ − x̄) on both sides:

Sxy = b Sxx  ⇒  b = Sxy / Sxx = r · sy / sx

3It is a minimum. The Hessian of S is [[2n, 2Σxᵢ],[2Σxᵢ, 2Σxᵢ²]] with determinant 4(nΣxᵢ² − (Σxᵢ)²) = 4n Sxx > 0 as soon as the xᵢ are not all equal, and 2n > 0. So S is strictly convex and the stationary point is the unique global minimum.

Population version

b = Cov(X,Y) / Var(X) = ρ σY / σX
a = μY − b μX

This is the best linear predictor of Y given X in the L² sense: the residual ε = Y − a − bX satisfies E[ε] = 0 and E[εX] = 0 (the normal equations), i.e. it is uncorrelated with X.

Residual variance and R²

Substituting b = Sxy/Sxx in S:

SSE = Syy − 2b Sxy + b² Sxx = Syy − Sxy²/Sxx = Syy(1 − r²)

Since SSE ≥ 0 this gives again |r| ≤ 1, and the proportion of the variance of y explained by the line is R² = r².

03 / Two regression lines

Why there are two lines and what r has to do with them

Regression is not symmetric: minimizing vertical errors (y on x) gives a different line than minimizing horizontal errors (x on y).

The two fitted lines

y on x:   ŷ = a + b x ,   b = Sxy/Sxx ,   a = ȳ − b x̄
x on y:   x̂ = a′ + b′ y ,   b′ = Sxy/Syy ,   a′ = x̄ − b′ ȳ

Both pass through the centroid (x̄, ȳ). Drawn in the same (x, y) plane, the second line has slope 1/b′.

Geometric mean of the coefficients

b · b′ = Sxy² / (Sxx Syy) = r²
|r| = √(b · b′)  ,   r = sign(b)·√(b · b′)

Since Sxx, Syy > 0, b and b′ have the sign of Sxy, hence the sign of r. Their product is non-negative and its square root is the geometric mean, which equals |r|.

What happens for different values of r

CaseCoefficientsGeometry of the two lines
|r| = 1b′ = 1/bThe two lines coincide: all points lie on one line.
0 < |r| < 1b·b′ = r² < 1Two distinct lines crossing at (x̄, ȳ); the x-on-y line is steeper in the plane. In z-scores their slopes are r and 1/r (regression to the mean).
r = 0b = b′ = 0Horizontal line y = ȳ and vertical line x = x̄: perpendicular.
Neither line is the inverse of the other unless |r| = 1, because each minimizes a different loss. Using r as a "slope in standardized units" shows it: ẑy = r·zx and ẑx = r·zy.

Link with online algorithms

Both lines can be computed in a single pass with O(1) memory, using the Welford-style update.

Welford 1962
x̄n = x̄n−1 + (xn − x̄n−1)/n ,   ȳn = ȳn−1 + (yn − ȳn−1)/n
Sxy,n = Sxy,n−1 + (xn − x̄n−1)(yn − ȳn)

The same update with y replaced by x (or x by y) gives Sxx and Syy. The lab below checks that the online Sxy agrees with the two-pass value.

05 / Proof

Independence implies uncorrelation

Independent variables are always uncorrelated. The converse is false, and the lab above contains a counterexample.

Theorem

Let X and Y be independent random variables with finite second moments. Then Cov(X,Y) = 0, and therefore ρ(X,Y) = 0 whenever σX, σY > 0.

Lemma: E[XY] = E[X]·E[Y] for independent X, Y

1Indicators. If X = 1A and Y = 1B with A ∈ σ(X), B ∈ σ(Y), independence means P(A ∩ B) = P(A)P(B), so E[XY] = E[1A∩B] = P(A∩B) = P(A)P(B) = E[X]E[Y].

2Simple functions. If X = Σᵢ αᵢ 1Aᵢ and Y = Σⱼ βⱼ 1Bⱼ (Aᵢ ∈ σ(X), Bⱼ ∈ σ(Y)), bilinearity of the expectation and step 1 give E[XY] = Σᵢⱼ αᵢβⱼ P(Aᵢ)P(Bⱼ) = E[X]E[Y].

3Non-negative variables. Take simple functions 0 ≤ Xₖ ↑ X and 0 ≤ Yₖ ↑ Y, each measurable with respect to σ(X) and σ(Y) respectively, so Xₖ and Yₖ are independent. Then XₖYₖ ↑ XY, and by monotone convergence E[XY] = lim E[XₖYₖ] = lim E[Xₖ]E[Yₖ] = E[X]E[Y] (the value +∞ is allowed).

4General case. Apply step 3 to |X| and |Y| (also independent): E|XY| = E|X|·E|Y| < ∞, so XY is integrable. Write X = X⁺ − X⁻ and Y = Y⁺ − Y⁻; each of the four pairs (X±, Y±) is independent and integrable, so by step 3 and linearity

E[XY] = E[X⁺Y⁺] − E[X⁺Y⁻] − E[X⁻Y⁺] + E[X⁻Y⁻] = (E[X⁺] − E[X⁻])(E[Y⁺] − E[Y⁻]) = E[X]E[Y]
∎

Conclusion of the theorem

Finite second moments make X and Y integrable and, by Cauchy–Schwarz, XY integrable, so the covariance is well defined. Using the lemma,

Cov(X,Y) = E[XY] − E[X]E[Y] = E[X]E[Y] − E[X]E[Y] = 0

and ρ = Cov(X,Y)/(σXσY) = 0.

∎
Measure-theoretic version. Independence means that the joint law is the product measure P(X,Y) = PX ⊗ PY. By Fubini's theorem (justified by E|XY| < ∞), E[XY] = ∬ xy dPX(x) dPY(y) = ∫x dPX · ∫y dPY = E[X]E[Y]. In the discrete case this is just Σₓ Σy xy p(x)q(y) = (Σₓ x p(x))(Σy y q(y)).
The converse is false

Uncorrelated but dependent

Let X be uniform on {−1, 0, 1} and Y = X². Then E[X] = 0 and E[XY] = E[X³] = 0, so

Cov(X,Y) = E[X³] − E[X]E[X²] = 0 − 0 = 0

yet Y is a function of X, so they are dependent: P(X=1, Y=1) = 1/3 but P(X=1)P(Y=1) = (1/3)(2/3) = 2/9.

A special case

Jointly Gaussian variables

If (X,Y) is bivariate normal and ρ = 0, the joint density factorizes into the product of the two marginal densities, so X and Y are independent. Only in this Gaussian case is "uncorrelated ⇔ independent" true.

Correlation detects linear dependence only. To detect general dependence one needs other tools, for instance mutual information or distance correlation.
