02 / Mathematical foundations

What each integral actually means.

These methods do not merely use different formulas: they organize measurable information differently.

01 / DOMAIN PARTITION

Riemann integral

Σ f(ξᵢ) Δxᵢ

Divide [a,b] into subintervals and sum sampled heights times interval widths. A function is Riemann-integrable when its upper and lower Darboux sums approach the same limit as the partition becomes fine.

02 / RANGE PARTITION

Lebesgue integral

∫₀∞ μ({f > t}) dt

For nonnegative measurable functions, the layer-cake identity expresses the integral through the measures of superlevel-set preimages. This is the range-partition method actually implemented in the lab, with analytical measures or a sampled estimate of each measure.

The classical simple-function construction instead partitions the range into disjoint bins Eⱼ and sums representative heights yⱼ times the measures of their preimages: Σⱼ yⱼ·μ(f⁻¹(Eⱼ)). Both viewpoints approximate the same nonnegative Lebesgue integral under appropriate refinement, but they are not identical finite sums.

03 / CONVERGENCE

When they agree

∫ᴿ f = ∫ᴸ f

On a finite interval, every bounded Riemann-integrable function is Lebesgue-integrable with the same value. Not every Lebesgue-integrable function is Riemann-integrable.

Dirichlet's function — a genuine difference

f(x) = 1 if x ∈ ℚ; 0 otherwise

Every interval contains rational and irrational numbers. Every lower Darboux sum equals 0 and every upper Darboux sum equals 1, so no Riemann integral exists.

But the rationals form a countable set of Lebesgue measure zero. Hence the Lebesgue integral on [0,1] equals exactly 0.

A rational midpoint grid samples only rational points and falsely displays a Riemann value of 1. This is not evidence for a Riemann integral; it exposes a limitation of a sampling rule.

Thomae's function — deceptively sparse spikes

f(p/q) = 1/q, f(irrational) = 0

For a rational p/q written in lowest terms, the height depends on its denominator. The function is discontinuous at rational points but continuous at irrational points.

It is Riemann-integrable because its set of discontinuities has measure zero; its Riemann and Lebesgue integrals both equal 0.

Finite rational grids still detect positive spikes, so convergence can look irregular. A nonzero finite sample does not contradict the zero integral.

Important methodological distinction. The primary range algorithm uses the layer-cake identity ∫₀∞ μ({f > t}) dt, approximated by K midpoint bins, with analytic superlevel-set measures. It is distinct from the classical simple-function sum Σⱼ yⱼ μ(f⁻¹(Eⱼ)). The new sampled version estimates those measures on M rational domain midpoints; this exposes the strong sampling bias of pathological functions (especially Dirichlet). Analytic measure queries are problem-specific oracles, so their timings are not a universally fair comparison against M function evaluations.

Improper integrals: why 1/√x is special

The function f(x)=1/√x is unbounded near x=0 and therefore is not Riemann-integrable in the ordinary bounded-function sense on [0,1]. Its improper Riemann integral and Lebesgue integral both equal 2.

∫₀¹ x⁻¹ᐟ² dx = 2

Its range extends to infinity. The level-set method numerically integrates up to a finite height T and uses the exact tail correction ∫ₜ∞ t⁻²dt = 1/T. This correction is explicitly identified as analytical information rather than free numerical accuracy.

04 / Explanation and implementation

Why the normal CDF needs numerical methods.

Explore the mathematical identity, the four algorithms, and the theorem explaining the absence of an elementary antiderivative.

01 / PROBABILITY

Normal CDF

Φ(z) = ∫₋∞ᶻ φ(t) dt

For Z ∼ N(0,1), the cumulative distribution integrates the normalized Gaussian density. Symmetry allows integration from 0 to |z| instead of −∞.

02 / EXACT SPECIAL FUNCTION

Error function

Φ(z) = ½[1 + erf(z/√2)]

The error function names a non-elementary integral exactly. Introducing a special function is an analytic representation, not a claim that numerical calculation is unnecessary.

03 / THEOREM

Liouville's theorem

∫ e⁻ˣ² dx is not elementary

Liouville's theorem on elementary integration restricts the form an elementary antiderivative can take. Applying its criterion proves that the Gaussian has no elementary antiderivative.

Method A — Adaptive Simpson quadrature

Use symmetry Φ(z)=½ ± ∫₀^{|z|}φ(t)dt. Simpson's rule approximates the integral from values at the endpoints and the midpoint. Adaptive refinement subdivides only when the estimated local error is too large.

S(a,b) = (b−a)[f(a)+4f((a+b)/2)+f(b)]/6

The implementation reuses already evaluated points and estimates the correction from the difference between a whole-interval approximation and its two half-interval approximations.

JavaScript · Simpson core
const S = (a,b,fa,fm,fb) =>
  (b-a)*(fa + 4*fm + fb)/6;
// Recursively split [a,b] until
// |S_left + S_right - S_whole| < 15*tol.

Complexity depends on the requested tolerance and the function's smoothness. The algorithm is flexible, but may require many density evaluations.

Method B — Error-function power series

NIST DLMF gives a convergent series for erf. The site uses an equivalent positive-term form for x ≥ 0, which avoids the large alternating cancellations of the elementary Maclaurin expression.

erf(x) = (2/√π)e⁻ˣ² Σ [2ⁿx²ⁿ⁺¹/(2n+1)!!]

The series is truncated when its newest contribution becomes sufficiently small relative to the accumulated sum.

JavaScript · Positive-term recurrence
let term = x, sum = x;
for (let n = 1; n < maxTerms; n++) {
  term *= (2*x*x)/(2*n+1);
  sum += term;
  if (term < tolerance*sum) break;
}
const erf = 2/Math.sqrt(Math.PI)
  * Math.exp(-x*x) * sum;

For very large negative z, computing Φ(z)=½−½erf(|z|/√2) suffers cancellation; tail-specific numerical methods are then preferable.

Method C — Fast erf approximation

The site implements the widely used Abramowitz–Stegun 7.1.26 polynomial approximation, with maximum absolute erf error about 1.5×10⁻⁷ under the published approximation.

erf(x) ≈ 1 − P(t)e⁻ˣ²,   t = 1/(1+0.3275911x)

The approximation uses a fixed number of arithmetic operations and one exponential evaluation, so it is efficient when moderate precision is sufficient.

It is not an exact analytical evaluation; the coefficients approximate the special function numerically.

Liouville's theorem — a concrete Gaussian proof

Liouville's theorem in differential algebra restricts elementary antiderivatives to an elementary derivative plus a finite sum of logarithmic-derivative terms. For the relevant special case f(x)eg(x), with f rational and g a nonconstant polynomial (such as g=−x²), the elementary-integrability criterion reduces to finding a rational function h(x) satisfying:

h′(x) + g′(x)h(x) = f(x)

Indeed, if such h exists, differentiating h(x)eg(x) gives f(x)eg(x). The difficult direction (that an elementary primitive would force a rational h) is the consequence of the Liouville/Risch criterion in this special setting; it is not a claim about arbitrary elementary h.

Set f(x)=1 and g(x)=−x². The equation becomes h′(x) − 2xh(x) = 1.

Suppose rational h has a finite pole of order m≥1. Its derivative has a pole of order m+1, whereas 2xh has a pole of order at most m. The pole cannot cancel. Since the right-hand side 1 has no poles, h cannot have finite poles.

A rational function with no finite poles must be a polynomial. Suppose h is a nonzero polynomial of degree d≥0. Then −2xh has degree d+1, whereas h′ has degree at most d−1. Hence h′−2xh has degree d+1 and cannot equal the constant 1. The zero polynomial also fails.

Therefore there is no rational solution h; by the elementary-integrability criterion, ∫e−x² dx is not elementary.

This argument explains the theorem's application rather than merely asserting the result. A rigorous treatment is linked below in Brian Conrad's paper.

From the Gaussian CDF to erf — every substitution step

Start with the standard normal density and use its symmetry about 0:

Φ(z) = ½ + (1/√(2π))∫₀ᶻ e−t²/2 dt

Make the substitution t = √2·s. Then dt = √2 ds, t²/2 = s², and the upper limit becomes s = z/√2:

Φ(z) = ½ + (1/√π)∫₀^{z/√2} e−s² ds

By definition, erf(u) = (2/√π)∫₀ᵘ e−s² ds, so:

Φ(z) = ½[1 + erf(z/√2)]

The formula is an exact special-function identity, even though erf itself generally requires numerical evaluation. It is valid for positive and negative z.

Method D — Composite trapezoidal rule

As a fourth independent numerical method, subdivide an interval [a,b] into N equal segments with spacing h=(b−a)/N. The composite trapezoid rule approximates an integral by:

Tₙ = h[½f(a) + Σₖ₌₁ⁿ⁻¹ f(a+kh) + ½f(b)]

When N doubles, old sample evaluations are reused and only the new midpoints are evaluated. The error estimator |T2N−TN|/3 follows the O(h²) behavior for smooth integrands. The method stops at the selected tolerance or a fixed safety cap of 131,072 subintervals. For negative tails, it integrates the small tail directly to avoid cancellation.

Why the normal CDF is still computable

The CDF is a perfectly well-defined function even though its indefinite integral is not elementary. It can be computed through numerical quadrature, convergent series and highly optimized special-function algorithms. The provided lecture notes on the normal distribution establish the Gaussian density and its normalization, while the NIST Digital Library of Mathematical Functions gives the precise definition and series of erf.

For probabilities in extreme tails, the direct expression ½[1+erf(z/√2)] can lose precision because floating-point subtraction cancels nearly equal numbers. High-quality numerical implementations may instead compute erfc, survival probabilities or logarithmic CDFs.

05 / Results & interpretation

What the experiments demonstrate.

Exercise 1 — Main conclusions

For bounded Riemann-integrable functions, well-constructed domain and range approximations converge to the same integral. Their finite-resolution accuracy and speed can differ significantly because their sampling and available analytical information differ.

For Dirichlet's function, the Lebesgue integral is 0 but the Riemann integral does not exist. Thomae's function has integral 0 in both senses, even though finite rational grids detect spikes.

For the unbounded function x−1/2, the improper Riemann integral and Lebesgue integral agree; a range truncation needs explicit treatment of the infinite tail.

Exercise 2 — Main conclusions

The normal CDF has an exact definition through a definite integral and the error function, but no representation using elementary antiderivatives. Adaptive quadrature and special-function methods provide accurate numerical values.

Adaptive Simpson provides controlled refinement; composite trapezoidal quadrature provides a second, generally O(h²) numerical integration method; the power series illustrates a special-function method; and the polynomial approximation offers inexpensive moderate-precision evaluation.

Accuracy must be assessed against a trusted independent reference, and computation time must be interpreted together with floating-point stability and the requested error tolerance.
