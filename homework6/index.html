A worked calculation from your dataset

Consider the first cell in the contingency table. If X takes the first row category and F takes the first column category, the expected count under independence is the product of the two marginal totals divided by N.

E₁₁ = (row total × column total) / N
Contribution₁₁ = (O₁₁ − E₁₁)² / E₁₁

The test statistic adds the contributions of every cell.

04 / Mathematical foundations

Why the test works.

Probability theory defines population independence. Descriptive statistics estimates distributions from observations. Statistical inference then tests whether observed discrepancies are compatible with the null hypothesis.

01 / POPULATION INDEPENDENCE

Joint = product of marginals

P(X=x,F=f) = P(X=x)·P(F=f)

Independence means the joint probabilities factorize for every pair of categories. Equivalently, when P(X=x)>0, knowing X does not change the distribution of F.

02 / EXPECTED FREQUENCIES

The null model

Eᵢⱼ = (Rᵢ · Cⱼ) / N

Rᵢ and Cⱼ are the observed row and column totals. The formula estimates how many observations would fall in each cell if the variables were independent.

03 / TEST STATISTIC

Sum of squared deviations

χ² = Σᵢ Σⱼ (Oᵢⱼ − Eᵢⱼ)² / Eᵢⱼ

Large discrepancies between observed and expected counts increase χ². The approximate null distribution has (r−1)(c−1) degrees of freedom.

From probability to frequencies

1

Joint frequency: Oᵢⱼ / N estimates P(X=xᵢ,F=fⱼ).

2

Marginal frequency: Rᵢ / N estimates P(X=xᵢ), while Cⱼ / N estimates P(F=fⱼ).

3

Conditional frequency: Oᵢⱼ / Rᵢ estimates P(F=fⱼ | X=xᵢ). Similarly, Oᵢⱼ / Cⱼ estimates P(X=xᵢ | F=fⱼ).

4

Independence: compare the conditional proportions with the overall marginal proportions. Consistent differences suggest association.

5

Inference: calculate χ², degrees of freedom and a p-value. Reject H₀ only when the evidence crosses the chosen significance threshold and test assumptions are appropriate.

The programmatic implementation

This is the core of the algorithm. It does not require manually counting every combination of categories.

JavaScript · core contingency-table logic
for (const [x, f] of observations) {
  observed[rowIndex.get(x)][colIndex.get(f)]++;
}

const N = observed.flat().reduce((a,b) => a+b, 0);
const rowTotals = observed.map(row =>
  row.reduce((a,b) => a+b, 0));
const colTotals = cols.map((_,j) =>
  observed.reduce((s,row) => s+row[j], 0));

const expected = observed.map((row,i) =>
  row.map((_,j) => rowTotals[i]*colTotals[j]/N));

const chi2 = observed.reduce((sum,row,i) =>
  sum + row.reduce((s,O,j) =>
    s + (O-expected[i][j])**2/expected[i][j], 0), 0);

The complete site also computes the right-tail probability using the regularized upper incomplete gamma function. All calculations happen locally in your browser; no dataset is uploaded to a server.

What the p-value means

The p-value is the probability, under the null hypothesis and the test's sampling assumptions, of obtaining a chi-square statistic at least as large as the observed one.

p = P(Χ²₍df₎ ≥ χ² observed | H₀)

A small p-value indicates evidence against population independence. A large p-value means the sample does not provide strong enough evidence to reject independence; it does not prove the variables are independent.

A low p-value is also not the probability that H₀ is false.

Assumptions and limitations

  • Each observation should represent an independent sampled unit.
  • Categories must be mutually exclusive and observations counted once.
  • The ordinary asymptotic χ² test requires sufficiently large expected counts; values below 5 are flagged here as a conservative warning.
  • The test requires at least two categories for each variable.
  • With sparse contingency tables, exact tests or Monte Carlo methods may be more appropriate.
  • For continuous quantitative variables, grouping into bins changes the question and may change the test result.
  • A significant association does not identify the direction of influence or establish a causal mechanism.
