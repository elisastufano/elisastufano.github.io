06 / Exercise 1 — Derivation

Welford's recurrence formulas.

Starting from Knuth's online mean recurrence, derive a stable online update for the sum of squared deviations (SS) and the unbiased sample variance.

Step-by-step mathematics

From Knuth to Welford

Given observations x₁, …, xₙ, let μₙ be the sample mean and SSₙ = Σᵢ₌₁ⁿ (xᵢ − μₙ)².

Update the mean using Knuth's formula.
μₙ = μₙ₋₁ + (xₙ − μₙ₋₁) / n
Set δ = xₙ − μₙ₋₁ and Δ = μₙ − μₙ₋₁ = δ/n. Because the old residuals sum to zero, Σᵢ₌₁ⁿ⁻¹ (xᵢ − μₙ₋₁) = 0.
Expand the first n − 1 squared residuals about the new mean.
Σᵢ₌₁ⁿ⁻¹ (xᵢ − μₙ)² = SSₙ₋₁ + (n − 1)Δ²
Add the newest observation. Since xₙ − μₙ = δ(n − 1)/n, expand both new quadratic terms:
SSₙ = SSₙ₋₁ + (n − 1)(δ/n)² + [δ(n − 1)/n]²
Collecting terms gives SSₙ = SSₙ₋₁ + δ²(n − 1)/n = SSₙ₋₁ + δ(xₙ − μₙ).
Obtain Welford's SS recurrence and sample variance.
SSₙ = SSₙ₋₁ + (xₙ − μₙ₋₁)(xₙ − μₙ)
sₙ² = SSₙ / (n − 1),   n ≥ 2

JavaScript implementation

Three lines of core logic.

Initialize count = 0, mean = 0, SS = 0. For each incoming score x, increment count first, then run the update below.

core recurrence · 3 lines
const delta = x - mean;
mean += delta / count;
SS += delta * (x - mean);
complete reusable estimator
function welford(scores) {
  let count = 0, mean = 0, SS = 0;
  for (const x of scores) {
    count++;
    const delta = x - mean;
    mean += delta / count;
    SS += delta * (x - mean);
  }
  return {
    mean,
    variance: count > 1 ? SS / (count - 1) : null
  };
}

Why Welford? Constant O(1) memory, O(n) total time, and better numerical stability than the naive E[X²] − E[X]² computation on observed samples.

Direct variance recurrence:
sₙ² = [(n − 2)sₙ₋₁² + (xₙ − μₙ₋₁)(xₙ − μₙ)] / (n − 1), for n ≥ 3. For n = 2, use SS₂ / 1. Variance is undefined with only one observation.

07 / Exercise 2 — Statistical inference

Why do these results matter?

The simulation connects two important statistical ideas: unbiased estimation and consistency as sample size increases.

01 / UNBIASEDNESS

Correct on average

The expected sampling mean equals μ = 5, and the expected sample variance (using n − 1) equals σ² = 10. Across many hackers, the averages of these estimates approach the population values.

02 / PRECISION

Less spread with larger n

The variance of an individual sampling mean is Var(x̄) = 10/n. The spread of the unbiased sample variance also decreases with n. Larger samples give more reliable estimates.

03 / INFERENCE

Learning about populations

In practice, μ and σ² are unknown. Estimators and their sampling distributions let us quantify uncertainty, construct confidence intervals and reason about a population from limited observations.

Exact theoretical variability

Why both sampling distributions narrow

Sampling mean

Var(x̄) = σ² / n = 10 / n

Hence SD(x̄) = √(10/n). Doubling n multiplies the standard deviation by 1/√2.

Unbiased sampling variance

Var(s²) = [μ₄ − (n − 3)σ⁴/(n − 1)] / n

For our distribution, the fourth central moment μ₄ = E[(X − 5)⁴] = 178 and σ⁴ = 100. This expression also tends to zero.

This exact variance-of-sample-variance formula assumes independent, identically distributed scores and a finite fourth central moment. The normal approximation is not needed for either formula.
